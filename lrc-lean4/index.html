Pinned formalization package

Lean 4 source

The package uses Lean 4.33.1 and Mathlib v4.33.1. Its main theorem proves that odd coloring is equivalent to zero mixed moment on every even support. GitHub Actions builds the library, runs Lean's independent environment checker, and audits axiom dependencies.
